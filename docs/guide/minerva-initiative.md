## 1. 这是什么：一句话概括

**MINERVA Initiative 是加拿大国防部（DND）与加拿大陆军通过 Innovative Solutions Canada（ISED 旗下创新采购平台）发起的一批并行挑战公告**，面向加拿大中小企业征集国产无人系统方案，覆盖情报监视侦察（ISR）、战术货物运输、极地作战、弹药/物资投送等多个战术场景。与 [DDI](./defence-drone-initiative.md) 的"持续滚动供应商资格池"模式不同，MINERVA 是**挑战奖金制（challenge-based）**：申请人直接针对某个挑战提交技术方案竞标合同，而不是先进池子再等定向需求。

::: info 目前已知的四个挑战（本文档覆盖范围）
1. **ISR 无人机**（Intelligence, Surveillance and Reconnaissance UAS）
2. **无人地面系统 · 战术货物运输**（Uncrewed Ground System, Tactical Cargo Movement）
3. **北极无人机**（Arctic Uncrewed Air System）
4. **货物/弹药投送无人机**（Uncrewed Air System, Cargo/Munition Drop）

不排除同一批次下还有其他未收集到的挑战（例如反无人机、海事系统等，参考 DDI 六大用例）。本文档只分析用户提供的这四条链接。
:::

## 3. 加拿大陆军当前无人机需求趋势（基于三个 UAS 挑战的推断）

::: tip 结论先行
陆军现阶段要的不是"更强的单一无人机"，而是一整套**国产、抗寒、单兵可携、低成本、可消耗、具备基础电磁抗扰能力**的战术无人机家族，优先补齐"班排级"侦察与后勤投送能力，并针对北极/北方作战场景专门优化。
:::

### 3.1 极端环境适应性是硬门槛，不是选配
三个 UAS 挑战全部要求 **-20°C 起步**，北极版进一步到 **-40°C**、抗风 **55 km/h**。这不是通用军规环境标准，而是明确针对加拿大本土北方/极地驻防场景定制的门槛——意味着任何投标方案，**基础气候适应性必须在方案设计阶段就内建**，而不是后期加装保温/加热组件。

### 3.2 全面转向"单兵可携行"小型化平台
ISR 与货物投送两个挑战都要求 VTOL 起降场地 **≤2m²**，可收纳进 **70升背包**，货物投送版还要求 **10分钟内**完成部署。陆军要的是**分队/单兵级别、免机场、快速展开**的系统，不是大型察打一体平台。

### 3.3 "简单易操作"贯穿全部需求描述
官方原文反复强调 "easy to operate"、"simple, durable, minimal training"。这透露出一个信号：陆军正从"专业操作员+专用无人机分队"模式，转向"普通士兵拿起来就能用"的消费级易用性思路。

### 3.4 系列化、模块化的"无人机家族"正在成形
三个挑战任务剖面不同（侦察 / 极地 / 物资投送），但**系统组件清单完全一致**（机体+载荷+地面站+电台+电池+天线）——这更像是同一批次里搭建一个**共享地面站/电台/电池架构、不同任务包**的模块化家族，而非孤立采购。

### 3.5 电磁频谱生存性开始成为需求（目前仅是"加分项"）
只有货物/弹药投送无人机明确把 **AES-256加密、光纤或非电磁通信、抗干扰**列为期望特性——这是三份文档里唯一出现"战场生存性/抗侦测"要求的地方，大概率是俄乌战场GPS欺骗、电子压制经验的直接投射。**目前只是加分项，不是强制项**，但预计会在后续批次中升级为硬性要求。

### 3.6 成本上限指向"可消耗"定位
北极版 ≤$60,000 CAD、投送版 ≤$40,000 CAD 的生产成本目标，相比传统军用无人机的造价低一个数量级，指向**规模化列装、战场损耗可接受**的定位，而非稀缺、需精心保护的高价值资产。

### 3.7 采购模式本身也是信号
MINERVA 走 Innovative Solutions Canada 挑战通道，$500K/15个月/约5份合同的规模是在**广撒网测试多家加拿大中小企业方案**，而非直接向传统军工巨头下单——资格要求（本土研发、本土用工、本土高管）背后的深层意图是**摆脱对外国无人机供应链的依赖**，与 [DDI 文档](./defence-drone-initiative.md#4-资格要求-eligibility) 中"Buy Canadian"的定位一致。

## 4. 平台选型初步调研：ISR 与货运无人机能否共用一款机型（排除北极版）

::: tip 结论
ISR 与货运/弹药投送无人机在环境适应性、VTOL起降占地（2m²）、70L背包收纳这些约束上高度一致，技术上可以用**同一款机体 + 可更换任务模块**（轻量光电吊舱 vs. 货物释放机构）覆盖两个任务剖面——货运版的重载余量（MTOW<25kg、载荷≥5kg）天然覆盖 ISR 版更轻的传感器需求。
:::

以下为初步方向性判断，非详尽尽调，具体型号数据未经核实：

| 候选 | 结论 |
|---|---|
| DJI Matrice 600 Pro（六旋翼） | 载荷/MTOW量级匹配，但折叠后体积远超70L，装不进背包；且为中国产品，供应链不合规 |
| DJI Matrice 300/350 RTK（四旋翼） | 折叠尺寸可进背包，但最大载荷仅约2.7kg，不达标；同样有供应链问题 |
| Anduril Ghost（四旋翼，美制） | 方向上最接近——战术级、可拆解入包、载荷模块化——但具体载荷/MTOW数字需核实 |

::: warning 需要后续尽调
市面上暂未找到同时满足"载荷≥5kg + MTOW<25kg + 可折叠入70L背包"且供应链合规的成熟现货平台，初步判断这个组合大概率需要定制/自研折叠机型。正式立项前需专门尽调核实。
:::

## 5. 两类公司分别该做哪些准备

MINERVA 与 DDI 有一个关键差异：**DDI 有专门的"通信与数据系统"和"创新与实验"赛道，纯软件公司可以独立申请；MINERVA 的四个挑战要求的交付物全部是"完整系统"（机体+载荷+地面站等）**，官方文本里没有任何一条挑战是"只交付软件/算法"。这个结构性差异直接决定了两类公司的准备方式完全不同。

### 4.1 WildFire AI（纯 AI 软件公司）该做哪些准备

<Badge type="danger" text="现实判断" /> **无法作为主承包商独立投标这四个 MINERVA 挑战**——交付物明确要求完整硬件系统（机体、地面站、电台、电池），纯软件/算法公司不具备独立交付资格。这一点和 DDI 不同，需要提前和团队讲清楚，避免误判机会窗口。

#### 真正的切入点：AI 感知能力作为"分包/组件"

::: tip 北极无人机的昼夜目标识别指标，正是 AI 感知的用武之地
北极无人机挑战明确列出了识别性能指标——白天人员 0.5km/车辆1km，夜间人员0.25km/车辆0.5km。这类指标最终依赖的是**检测算法的性能**，而不只是传感器硬件本身。这是三个挑战里唯一一处"AI公司的核心能力直接对应验收指标"的地方。
:::

| 行动项 | 优先级 | 说明 |
|---|---|---|
| 明确当前算法在指定距离下的人员/车辆识别准确率与延迟数据 | <Badge type="danger" text="高" /> | 这是能否说服硬件 OEM 组队的第一手"能力证据"，需要在IR/EO低照度条件下有实测数据，不能只讲白皮书指标 |
| 主动接触已在准备投标的加拿大无人机硬件厂商，提前建立组队关系 | <Badge type="danger" text="高" /> | 本轮时间窗口已非常紧（详见第1节），更现实的目标是为**下一批次**或**货物/弹药投送无人机**（10/5截止）做分包商角色的联合投标准备 |
| 评估自身感知算法是否可移植到光纤/非电磁通信链路的低带宽/高延迟场景 | <Badge type="warning" text="中" /> | 投送无人机把"非电磁通信"列为加分项，若算法依赖持续高带宽云端推理，需要提前验证边缘端离线推理能力 |
| 转向监控 DDI 的"通信与数据系统"赛道，而非 MINERVA | <Badge type="warning" text="中" /> | 该赛道天然适配纯软件公司独立投标，参见 [DDI 文档 8.1 节](./defence-drone-initiative.md#8-1-画像一-纯-ai-saas-技术背景公司) |
| 提前准备数据安全/网络安全就绪度文档（加密标准、密钥管理、数据驻留） | <Badge type="tip" text="低" /> | 国防类数据处理项目迟早会问到这些，不必等到中标后临时补 |

::: warning MINERVA 不是当前最佳赛道，但值得留意下一轮
如果贵司确实想切入 MINERVA 这类"整机挑战"，现实路径是**先成为某个硬件 OEM 投标方案里的感知/AI子系统供应商**，而不是自己注册投标。建议把精力优先放在 DDI 的软件赛道上，MINERVA 这边以"组队关系建设"为主，而不是自己准备一份不可能独立交付的申报材料。
:::

### 4.2 无人机硬件公司（尚未成立）该做哪些准备

<Badge type="danger" text="现实判断" /> 假设这是一家**还没成立**的新公司，四个 MINERVA 挑战里没有一个是"从零起步"能在本轮窗口内实际交付的——哪怕是仅剩约2周的货物/弹药投送无人机，从公司注册、团队组建到具备可投标的技术方案，正常也需要数月。更现实的用法是：**把这批公告的技术门槛当作"从0到1"能力建设路线图的设计基准**，瞄准下一轮或未来类似批次，而不是仓促冲刺本轮。

#### 第一步：满足基本资格门槛

| 事项 | 说明 |
|---|---|
| 公司注册 | 联邦或省级注册的**营利性加拿大公司**，这是所有 ISC 挑战的前提，越早办完越好，不要等技术方案成型才启动 |
| 团队规模 | 需保持在 **≤500 名全职员工**的中小企业门槛内（对新公司而言通常不是问题） |
| 研发地点与用工 | 研发活动须在加拿大境内进行，多数工资须支付给加拿大本地员工 |
| 高管国籍 | 至少 **50%** 高级管理层须为加拿大人/加拿大居民 |
| 平台注册 | 在 **Innovative Solutions Canada** 平台单独注册账号——这与 [DDI 使用的 CanadaBuys/SAP Business Network](./defence-drone-initiative.md#8-2-画像二-无人机研发制造公司) 是两套不同系统，两边都要注册 |

#### 技术能力从零搭建：建议的任务剖面优先级

三个 UAS 挑战对"从零起步"的公司而言难度差异很大，建议按以下顺序评估切入：

| 挑战 | 从零起步的难度 | 理由 |
|---|---|---|
| ISR 无人机 | 🟢 相对可行 | 温度/抗风/续航要求在常规商用级无人机工程能力范围内，VTOL+2m²起降是行业标准架构，是最适合作为"第一款产品"的任务剖面 |
| 货物/弹药投送无人机 | 🟡 中等 | 基础平台要求与ISR接近，但需要新研发**载荷投放机构**，且涉及弹药的部分会引入额外的出口管制/合规复杂度（见下文），建议先做非弹药的纯物资投送变体 |
| 北极无人机 | 🔴 难度最高 | **-40°C**、55km/h抗风、20km半径、90分钟续航全面超出常规商用级设计基线，电池化学体系、结构材料、地面站严寒可靠性都是独立的工程攻坚项，不建议作为新公司的第一款产品 |

#### 成本目标是最大的隐性风险，需要从第一天就设计到成本

::: danger 光电吊舱本身的市场价格，可能就已经逼近整机成本上限
行业内满足 LWIR 热成像 + EO 光学变焦 + 激光测距 三合一功能、且走非中国供应链（Workswell、Teledyne FLIR 等西方/盟友厂商）的军规级吊舱，市场参考价普遍在 **CAD 20,000–35,000** 区间（⚠️ 需核实：具体报价会随时间和型号波动，建议在方案设计前直接找供应商询价确认）。而北极无人机的整机生产成本目标是 **≤$60,000 CAD**，投送版是 **≤$40,000 CAD**——单是吊舱就可能吃掉大半预算，留给机体、地面站、通信、电池的空间非常薄。

对一家新公司来说，这意味着**产品定义阶段就必须做成本工程（design-to-cost）**，而不是先做功能齐全的方案再回头砍成本——要么选用更便宜的传感器方案，要么接受牺牲部分非核心指标（如变焦倍数、探测距离）来换取达标的整机成本。
:::

#### 供应链策略需要从第一天就定调，而不是事后补救

::: tip 与其"合规改造"，不如"合规出生"
[DDI 文档](./defence-drone-initiative.md#8-2-画像二-无人机研发制造公司) 中分析的现有硬件公司案例，之所以有优势，是因为它的供应链策略（电机、通信链路、GNSS、LiDAR 全走美/加/比利时等盟友供应链，规避中国供应商）本来就是为满足政府采购要求而设计的。对一家**新公司**而言，这个决策成本更低——因为还没有任何一条中国供应链需要"替换"，可以从选型清单的第一行就直接锁定盟友供应链来源，避免后期为了投标资格推倒重做 BOM。
:::

#### 弹药/投送类产品线需要提前做合规评估

::: warning 涉及弹药载荷的产品线，出口管制与合规成本远高于普通民用无人机
一家新公司如果考虑覆盖"货物/弹药投送"这类需求，在投入研发前应先评估**出口管制分类（是否落入 ITAR/加拿大出口管制清单）、武器级安全认证、责任保险**等合规成本——这些不是产品工程问题，而是公司注册结构和业务范围层面的决策，建议在立项前就找专业法务/合规顾问过一遍，而不是等产品做出来才发现无法交付。
:::
