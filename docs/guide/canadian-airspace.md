# 加拿大空域分类

> 法律依据：**CAR Part VI, Subpart 1 — 601.02 Airspace Classification**；详细划定见 **Designated Airspace Handbook (DAH)**

加拿大遵循 ICAO 标准，将空域划分为 **7 个类别（Class A–G）**，分三大组：

| 组别 | 类别 | 管制性质 |
|---|---|---|
| 受控空域 | A、B、C、D、E | ATC 提供间隔服务，进入有限制 |
| 不受控空域 | G | 无 ATC 间隔，飞行员自负安全 |
| 特殊用途空域 | F | 限制或咨询性质，视具体指定而定 |

---

## Class A — 高空受控空域

| 项目 | 详情 |
|---|---|
| 高度范围 | **FL180（18,000 ft / 5,486 m MSL）至 FL600（60,000 ft / 18,288 m）** |
| 允许飞行规则 | **仅 IFR** |
| 进入要求 | ATC 放行或部长授权 |
| 转发器（Transponder） | 必须 |
| 无线电 | 必须（双向） |

::: info RPAS 影响
Class A 起始高度远超任何 RPAS 运行包线，**实际上不涉及无人机运营**。
:::

---

## Class B — 高空过渡受控空域

| 项目 | 详情 |
|---|---|
| 高度范围 | **12,500 ft（3,810 m）MSL 至 FL180（18,000 ft / 5,486 m）** |
| 允许飞行规则 | IFR + VFR |
| 进入要求 | IFR 和 VFR 均须取得 ATC **放行（Clearance）** |
| 转发器 | 必须 |
| 无线电 | 必须（双向） |

::: info RPAS 影响
同 Class A，高度超出所有 RPAS 运行范围，**不适用于无人机**。
:::

---

## Class C — 大型机场终端受控空域

Class C 包围加拿大主要国际机场（如多伦多、温哥华、蒙特利尔、卡尔加里等），通常从地面或低高度延伸至 **3,000–7,000 ft（914–2,134 m）AAE**（Airport Elevation 以上）。

| 项目 | 详情 |
|---|---|
| 高度范围 | 地面 / 低高度 至发布高度（因机场而异） |
| 允许飞行规则 | IFR + VFR |
| IFR 进入 | 需 ATC 放行 |
| VFR 进入 | 需 ATC 放行；无线电设备例外（日间 VMC 可申请授权） |
| 转发器 | 必须 |
| ATC 关闭时 | 降级为 **Class E** |

::: danger RPAS 关键限制
进入 Class C 空域须事先取得 **RPAS 飞行授权（RASCFA）**，通过 NAV CANADA 的 [NAS 飞行请求系统](https://www.navcanada.ca) 或 Transport Canada 提交申请。未经授权进入属违规，可面临高额罚款。
:::

---

## Class D — 中小型管制机场受控空域

Class D 包围设有管制塔台但通常无雷达的机场，一般从地面延伸至 **3,000 ft（914 m）AAE**。

| 项目 | 详情 |
|---|---|
| 高度范围 | 地面 至 ~3,000 ft（~914 m）AAE（因机场而异） |
| 允许飞行规则 | IFR + VFR |
| 进入要求 | 须建立**双向无线电联系**；无线电设备例外（日间 VMC 可申请授权） |
| 转发器 | 视 DAH 指定，部分区域须配备 |
| ATC 关闭时 | 降级为 **Class E** |

::: danger RPAS 关键限制
与 Class C 相同，须事先取得飞行授权。规则适用于地面至空域上限的全部高度，**即使低空飞行也需授权**。
:::

---

## Class E — 受控过渡空域

Class E 是应用最广泛的受控空域，覆盖航路（Airways）、进近过渡区域、以及 Class C/D 关闭后的接管区域。

| 项目 | 详情 |
|---|---|
| 高度范围 | 因区域而异（通常从 **700 ft（213 m）或 1,200 ft（366 m）AGL** 开始） |
| 允许飞行规则 | IFR + VFR |
| IFR 进入 | 须 ATC 放行 |
| VFR 进入 | **无需放行**，但须维持 VMC |
| 转发器 | 仅 DAH 指定的 Class E 区域须配备 |

::: warning RPAS 影响
大多数 RPAS 在 **400 ft AGL（122 m）以下**飞行，通常处于 Class E 下方的 Class G 空域。但在航路附近、进近区域或特定地形条件下，Class E 可能从 **700 ft AGL（213 m）** 起始，与低空 RPAS 运行高度存在交叠——务必查阅当地 DAH 或使用 NAV Drone App 确认。
:::

---

## Class F — 特殊用途空域

Class F 不是单一空域，而是一类标注，覆盖军事、危险、或特定活动区域。分两种性质：

| 类型 | 代码前缀 | 性质 | 进入要求 |
|---|---|---|---|
| **限制区（Restricted）** | CYR | 未授权进入违法 | 须取得控制机构授权 |
| **咨询区（Advisory）** | CYA | 建议回避，不强制 | 无需授权，但飞行员须知晓活动 |

**常见 Class F 场景：**
- `CYR` — 军事射击靶场、核电站周边、边境缓冲区
- `CYA` — 跳伞区、滑翔机活动区、模型飞机场

::: danger RPAS 进入限制区（CYR）
必须联系指定控制机构（通常为军方或 NAV CANADA）取得明确授权。无授权进入可能触发严重法律后果。
:::

::: tip RPAS 进入咨询区（CYA）
虽无强制要求，建议进入前通过相关机构了解活动状态，规避碰撞风险。
:::

---

## Class G — 不受控空域

Class G 是所有未被指定为其他类别的空域，也是**绝大多数 RPAS 合规运行的主要空域**。

| 项目 | 详情 |
|---|---|
| 高度范围 | 地面至受控空域下限（通常 **700–1,200 ft（213–366 m）AGL**，因区域而异） |
| 允许飞行规则 | IFR + VFR |
| ATC 间隔服务 | **不提供**，飞行员自负安全 |
| 进入要求 | **无需放行或许可** |
| 转发器 | 不强制（除非进入 C/D 等受控空域） |

::: tip RPAS 标准运行窗口
按照 CAR Part IX：
- **400 ft AGL（122 m）以下的 Class G 空域**是小型/微型 RPAS 的合规运行区间
- 只要远离机场、受控空域及禁区，无需任何 ATC 授权
- 使用 **NAV CANADA 的 Drone app** 实时确认飞行点的空域类别
:::

## 各类别汇总对比

| 类别 | 管制性质 | RPAS 进入要求 | 典型高度下限 |
|---|---|---|---|
| A | 受控（IFR Only） | 不适用 | FL180（5,486 m） |
| B | 受控 | 不适用 | 12,500 ft（3,810 m）MSL |
| C | 受控 | **须取得飞行授权** | 地面（主要机场周边） |
| D | 受控 | **须取得飞行授权** | 地面（管制塔台机场周边） |
| E | 受控（VFR 免放行） | 注意低空交叠 | ~700–1,200 ft（213–366 m）AGL |
| F-CYR | 限制 | **须控制机构授权** | 因区域而异 |
| F-CYA | 咨询 | 无强制，建议了解活动 | 因区域而异 |
| G | 不受控 | **无需授权** | 地面 |

---

## 与 Standard 922 的关联

Standard 922 中的 **922.04 受控空域运行** 直接对应 Class C 和 Class D 空域：飞行器须能将侧向位置误差控制在 ±10 m、高度误差在 ±16 m 以内，这是进入受控空域前须通过安全申报验证的技术指标。

> ⚠️ 需核实是否仍为最新版本：加拿大 2025 年对无人机法规进行了更新（见 Transport Canada 2025 Summary of Changes），建议与官方最新版 DAH 及 CAR Part IX 对照确认。
